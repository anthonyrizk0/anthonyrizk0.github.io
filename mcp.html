Connect via MCP

Ask about my background from your own AI assistant using MCP (Model Context Protocol). This server uses the same source material as the Ask box on my site.

https://ask.anthonyrizk.me/mcp
Streamable HTTP · no authentication · ask_about_anthony(question)

Setup

In a client that supports remote MCP servers, add the URL above and choose Streamable HTTP if asked for a transport. No API key or custom headers are needed. You can name the server anthony.

Codex CLI
codex mcp add anthony --url https://ask.anthonyrizk.me/mcp
VS Code / GitHub Copilot

Run MCP: Add Server from the Command Palette, choose HTTP, and enter the URL above.

Cursor

Add this entry to ~/.cursor/mcp.json, merging it with any existing mcpServers entries: 

{
  "mcpServers": {
    "anthony": {
      "url": "https://ask.anthonyrizk.me/mcp"
    }
  }
}
Claude Code
claude mcp add --transport http anthony https://ask.anthonyrizk.me/mcp

More setup details: Codex · VS Code · Cursor · Claude Code.

Asking questions

Once connected, ask your assistant to use ask_about_anthony. For example: “Ask Anthony's MCP server about his work on PlantVision.”

Answers come from files I've written about my roles and projects. The server doesn't search the web and is instructed to say when something isn't covered.

  • Each call is independent. Include the relevant context in follow-up questions.
  • Ask about a specific role, project, or technology for a more detailed answer.
  • If the information isn't covered, try a different question or contact me directly.

Usage limits

The endpoint is public, with rate limits, a response deadline, and a daily spending cap. If it reaches its daily limit, try again the next day or use the Ask box, which has a separate limit.
